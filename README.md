# معهد القديس ديديموس للمرتلين

واجهة عربية متجاوبة قابلة للتثبيت كـ PWA، مع حفظ تقدم التعلّم على الجهاز وربط اختياري بـ Supabase.

## الحالة الحالية

- يعمل التصفح محلياً دون حساب، ويُحفظ التقدم والمفضلة لكل مستخدم متصفح على الجهاز.
- يمكن تثبيت غلاف الموقع، وتُخزّن ملفات الموقع مؤقتاً بعد أول زيارة عبر HTTPS أو `localhost`.
- إذا رُبط Supabase، تقرأ الواجهة المناهج والألحان والإعلانات، وتتيح تسجيل الدخول والنتائج وإدارة بعض المحتوى بحسب الدور.
- قاعدة البيانات والملفات التعليمية الرسمية غير مرفقة في الملفات التي زُوّدت بها المحادثة. لذلك تبدأ المراحل وتصنيفات الألحان فارغة، ولا تظهر إعلانات أو نتائج مختلقة.
- لا يوجد اتصال فعلي بـ Supabase أو Google Drive حتى الآن. واجهة استيراد Drive ومزامنة الملفات التلقائية تحتاج إلى خدمة خادم ومفاتيح حساب المعهد.
- إضافة الدروس في لوحة الإدارة تقبل روابط فقط في هذه النسخة؛ رفع الملفات مباشرةً وإدارتها من مخزن ملفات غير موصول.
- النتائج وحسابات المستخدمين تحتاج إعداد Auth والصلاحيات. لا تستخدم الوضع المحلي لحفظ نتائج أو معلومات شخصية.

## التشغيل

يمكن فتح `index.html` لمعاينة الواجهة. ميزات PWA والعمل دون اتصال تتطلب تقديم الملفات عبر HTTPS أو `localhost` لأن المتصفحات لا تسجل Service Worker من `file://`.

## إعداد Supabase

1. أنشئ مشروع Supabase تابعاً للمعهد.
2. شغّل `backend/schema.sql` في SQL Editor. يضيف المخطط الجداول وسياسات RLS ويهيئ الفرق الدراسية الخمس.
3. أنشئ حسابات المستخدمين من لوحة Supabase Auth. يحصل المستخدم الجديد على دور `student` تلقائياً.
4. رقِّ حساب المدير الأول يدوياً من SQL Editor بعد إنشاء الحساب، باستبدال البريد بعنوانه:

   ```sql
   update public.profiles p
   set role = 'admin'
   from auth.users u
   where p.id = u.id and u.email = 'admin@example.org';
   ```

5. انسخ `config.example.js` إلى `config.js` وضع عنوان المشروع ومفتاح `anon` العام. المفتاح العام ليس بديلاً عن RLS؛ لا تضع `service_role` أو أسرار Google في ملفات المتصفح.
6. ارفع المجلد إلى استضافة HTTPS. راجع سياسات RLS وعناوين إعادة التوجيه في Auth قبل دعوة الطلاب.

المخطط يسمح بمزامنة المناهج والألحان والإعلانات وتقدم الدروس والنتائج بين الأجهزة عبر قاعدة البيانات. الحفظ دون اتصال للتقدم يعمل محلياً؛ مزامنة التغييرات التي أُجريت أثناء انقطاع الاتصال لم تُنفّذ بعد.

## Google Drive

تكامل Drive الفعلي غير موجود في هذه الحزمة. لا تلصق مفاتيح OAuth أو بيانات دخول Google في `config.js`. يلزم تنفيذ وظيفة خادم تتحقق من دور المستخدم، وتستخدم Google Drive API من الخادم، وتتحقق من إمكانية الوصول إلى الملفات قبل نشر بياناتها. يلزم كذلك تشغيل مزامنة مجدولة أو Drive Changes API لتحديث المواد تلقائياً. حتى تجهيز ذلك، لن تعرض المكتبة أي ملف Drive.

## محتويات الحزمة

- `index.html`, `styles.css`, `app.js`: واجهة الموقع والتفاعلات.
- `manifest.webmanifest`, `sw.js`: تعريف التثبيت والتخزين المؤقت للغلاف والمواد من نفس النطاق.
- `config.example.js`: نموذج إعداد علني آمن للمتصفح.
- `backend/schema.sql`: مخطط أولي لقاعدة البيانات وسياسات الوصول.
- `logo.png`: الشعار المرفق.
